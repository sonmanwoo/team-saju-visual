# 네 사람, 여섯 개의 관계

손만우 · 오진호 · 홍윤기 · 정다솔의 사주 명식과 전통 명리 관계를 살펴보는 인터랙티브 HTML 리포트입니다.

**[공개 페이지 열기](https://sonmanwoo.github.io/team-saju-visual/)** · [기존 글로 읽기](https://gist.github.com/sonmanwoo/2ab247cd9afe48b15762c94a6f172c71)

## 살펴볼 수 있는 내용

- 네 사람의 일간과 개인 풀이
- 여섯 쌍의 관계와 합·충 등 전통 명리 규칙의 글자별 근거
- 년주·월주·일주 6글자의 오행 개수와 팀 전체 24글자 분포
- 시간 보정의 가정, 계산 범위, 출처
- 전체 내용 인쇄와 HTML 저장

이 자료는 전통 명리의 상징을 활용한 오락적 해석입니다. 실제 성격·능력이나 관계의 결과를 검증하는 자료가 아닙니다. 조합은 정해진 글자 사이의 대표적인 관계를 비교하며, 궁합 점수나 좋고 나쁨의 순위를 부여하지 않습니다.

## 계산 범위

한국 출생·양력이라는 정보를 바탕으로 년주·월주·일주를 비교합니다. 출생 도시와 정확한 분은 확인되지 않았으므로 **시주는 오행 분포와 관계 계산에서 제외**합니다. 오행 분포는 보이는 글자를 대표 오행으로 센 값이며 지장간·계절 가중치·신강신약을 계산하지 않습니다.

합 관계가 나타난다고 합화가 성립하는 것으로 보지 않습니다. 여러 사람의 글자를 합쳐 하나의 원국이나 완성된 삼합국으로 판단하지 않습니다.

## 파일

- `index.html`: CSS·JavaScript·SVG가 모두 포함된 단일 HTML. 내려받아 브라우저에서 바로 열 수 있습니다.
- `team-saju-reading.md`: 기존 풀이 원문
- `.nojekyll`: GitHub Pages에서 정적 HTML을 그대로 배포하기 위한 설정

외부 라이브러리, 추적 코드, 분석 도구, 로그인 없이 동작합니다. 근거 링크를 누르면 해당 외부 사이트가 열립니다.
